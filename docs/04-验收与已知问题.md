## 如何在你自己的盒子上验收（只读）

**前提：** 已经得到 Android ADB 授权，`adb devices -l` 真正显示可用设备。以下命令不执行刷机：

```bash
adb devices -l
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.sdk
adb shell getprop ro.product.device
adb shell getprop sys.boot_completed
adb shell getprop ro.build.type
adb shell getprop ro.build.tags
adb shell cat /proc/version
adb shell cat /proc/meminfo
adb shell dumpsys display
adb shell dumpsys power
```

期望至少观察到：

```text
Android: 6.0.1
SDK: 23
device: p211
sys.boot_completed: 1
HDMI: 实际画面为 1080p，能看到桌面
```

**上面的 HDMI 行不是 `getprop` 单条命令返回，而是屏幕与显示状态的综合人工验收条件。**

还要手工完成：

1. 遥控器 HOME、返回、方向、音量等按键；
2. 播放一段实际的 1080p H.264 + AAC 视频，确认**真实扬声器声音**和完整播放 10 分钟以上；
3. 将设备**正确重启**，再次检查系统版本、画面、网络、遥控及播放器；
4. 单独测试机器是否能正常从待机恢复；区分浅睡眠、深睡眠和关机；
5. 如使用 Emby/IPTV，分别验证服务器登录、字幕、硬解、音频格式与节目单。

这些手工项目是后续用户可复现实验的建议，**不是已经替本站设备全部完成的历史结论**。
